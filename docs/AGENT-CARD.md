## 2. Призначення
- Предметна область: рівні ізоляції транзакцій SQL та аномалії паралельного виконання
- Зв'язок із кваліфікаційною роботою: варіант 10
- Що робить агент: відповідає на питання про рівні ізоляції (Read Uncommitted, Read Committed, Repeatable Read, Serializable, Snapshot) і аномалії (dirty read, non-repeatable read, phantom read) лише за перевіреними даними середовища; для відсутніх об'єктів повідомляє, що даних немає.
- Типові запити: «Розкажи про рівень ізоляції Read Committed»; «Порівняй Read Uncommitted і Serializable»; «Які аномалії допускають Read Committed, Repeatable Read і Serializable?»
- Чого агент не робить: не виконує SQL, не підключається до СУБД, не описує рівні поза середовищем (наприклад, Cursor Stability), не дає рекомендацій з налаштування конкретної СУБД.

## 3. Архітектура
| Дія | Аргументи | Детермінована? | Змінює середовище? |
|---|---|---|---|
| lookup_isolation_level | name | так | ні |
| lookup_anomaly | name | так | ні |
| finish | answer | — | ні |

- Умови зупинки: finish; MAX_STEPS = 6; MAX_LLM_CALLS = 8
- Обробка відмов: невідома дія, відсутній аргумент, хибний тип, невалідний JSON → ERROR як спостереження; NOT_FOUND для відсутнього об'єкта; HTTP 429 → HttpRetryOptions (ADK) / пауза між запусками

## 6. Результати експерименту
Повні сирі дані: `manual-agent/experiments/raw_results.json` (one-shot і власний агент),
`experiments/adk/` (події ADK-агента). Зведені метрики: таблиця 7 звіту.

| Тип | One-shot (правильність / час) | Власний агент (правильність / час) | ADK (правильність / час) |
|---|---|---|---|
| A | 2 / 3.79 с | 2 / 2.11 с | 2 / 1.5 с* |
| B | 2 / 3.81 с | 2 / 3.01 с | 2 / 3.8 с |
| C | 2 / 3.75 с | 2 / 3.81 с | 2 / 1.9 с* |
| D | 0 (вигаданий опис) / 2.92 с | 2 / 1.84 с | 2 / 3.2 с |
| E | 2 / 2.68 с | 2 / 0.91 с | 2 / 1.5 с |

\* ADK для A і C виконано на gemini-3.1-flash-lite: денну квоту gemini-3.5-flash вичерпано (429).
Головний результат: на запиті D one-shot вигадав опис Cursor Stability, а обидва агенти
повернули NOT_FOUND і визнали відсутність перевірених даних.

## 7. Відомі обмеження та ризики
- Середовище містить 5 рівнів і 3 аномалії; усе інше — NOT_FOUND.
- Поведінка моделі недетермінована; траєкторії можуть відрізнятися між запусками.
- Дані навчальні, відкриті; безкоштовний рівень Gemini API може використовувати запити для покращення продуктів Google.
- Ризики OWASP LLM: LLM01, LLM02, LLM05, LLM06, LLM09, LLM10 (див. звіт).
